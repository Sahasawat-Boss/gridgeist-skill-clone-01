05 / Architecture

One pipeline.
Every source.

Cadence 2.4 connects sources, storage, correlation, and delivery before any dashboard is drawn. The pipeline stays proportional to your stack.

01 / IngestRaw events
02 / NormalizeUnified schema
03 / SurfaceReadable signal
SourcesWhere it starts.

CI runs, APM traces, error trackers, and flag providers stream in over webhooks or the CLI.

ci → apm → flags
StorageWhat it keeps.

Events land in an append-only store you host—queryable, exportable, and yours to retain.

append → query → export
CorrelationHow it connects.

Deploy windows bind metrics to changes, so a spike always has a suspect commit.

window → bind → suspect
DeliveryWhere it lands.

Status page, changelog, Slack, and webhooks fire only when a release actually stabilizes.

08 / Get started

Run it once.
Read every release.

01 / DOCKERRECOMMENDED

Pull the self-hosted image, point it at your event sources, and open the console on localhost.

docker run -p 7070:7070 \ -v cadence-data:/data cadence/console:2.4
02 / CLISEND EVENTS

Report a deploy from any CI job.

npx @cadence/cli deploy --service checkout --version 2.4.0
03 / UPDATEEXPLICIT

Pin a tag and upgrade when you choose; updates never run silently.

docker pull cadence/console:2.4 npx @cadence/cli self-update
